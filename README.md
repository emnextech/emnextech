## 👋 About me

- 🛠️ I design, build and deploy **full-stack products**: web apps, APIs, mobile apps and automation.
- 🎓 Much of my work solves problems I see around me: **students** finding past papers, **schools** printing ID cards, **workshops** tracking repairs.
- 🚀 Currently shipping **[CUZ Past Papers](https://cuzpastpapers.vercel.app)** (launched October 2026) and growing **[IDLab](https://idlab.emnextech.dev)**.
- 📈 I also build **trading automation**: Telegram-controlled bots, signal tools and MQL5 strategies.
- 🤝 Open to freelance and collaboration work through **[emnextech.dev](https://emnextech.dev)**.
